Միջանկյալ 1-ի 24 հարցերի հիմնական բանաձևերը՝ հարցերի համարներով։ Ամբողջական պատասխանները՝ հարցերի բաժնում։ Տպելիս ամեն ինչ տեղավորվում է մեկ A4 էջում։

Վիճակի պարամետրեր և իդեալական գազ

1Պարամետրեր \(\upsilon=\frac{V}{m}\ \left[\frac{\text{մ}^3}{\text{կգ}}\right],\ \ \rho=\frac1\upsilon,\ \ p_{\text{բաց}}=p_{\text{մթն}}+p_{\text{ավել}},\ \ T=t+273{,}15\) \(\frac{m\bar w^2}{2}=\frac32k_BT,\quad F(p,\upsilon,T)=0\)
2Իդեալական գազի օրենքներ \(T{=}\text{const}:\ p\upsilon=\text{const};\ \ p{=}\text{const}:\ \frac{\upsilon_1}{\upsilon_2}=\frac{T_1}{T_2};\ \ \upsilon{=}\text{const}:\ \frac{p_1}{p_2}=\frac{T_1}{T_2}\) \(\frac{p_1\upsilon_1}{T_1}=\frac{p_2\upsilon_2}{T_2},\ \ \upsilon_\mu=22{,}414\ \tfrac{\text{մ}^3}{\text{կմոլ}},\ \ p=\sum p_i\)
3Վիճակի հավասարում \(p\upsilon=RT,\ \ pV=mRT,\ \ p\upsilon_\mu=R_\mu T,\ \ R=\frac{R_\mu}{\mu},\ \ R_\mu=8314\) Ջ/(կմոլ·Կ) \(R_{\text{օդ}}=287\) Ջ/(կգ·Կ), \(\left(p+\frac{a}{\upsilon^2}\right)(\upsilon-b)=RT\)

Առաջին օրենք, աշխատանք, ջերմունակություն

4I օրենք (ներքին էներգիա) \(q=\Delta u+\ell,\ \ dq=du+p\,d\upsilon,\ \ du=c_\upsilon dT,\ \ \oint du=0\)
5I օրենք (էնթալպիա) \(i=u+p\upsilon,\ \ dq=di-\upsilon\,dp=c_pdT-\upsilon\,dp\)

\(-\upsilon\,dp\)՝ տնօրինելի աշխատանք

6Դեֆորմացիայի աշխատանք \(d\ell=p\,d\upsilon,\ \ \ell=\int_{\upsilon_1}^{\upsilon_2}p\,d\upsilon\) (մակերես \(p\)–\(\upsilon\)-ում) \(\ell_{p}=R(T_2-T_1),\ \ell_T=RT\ln\frac{\upsilon_2}{\upsilon_1},\ \ell_{\text{ադ}}=\frac{R}{k-1}(T_1-T_2)\)
7Ջերմունակություն \(c=\frac{dq}{dT},\ \ c_m=\frac{q}{T_2-T_1},\ \ c_\mu=\mu c,\ \ c_n=c_\upsilon\frac{n-k}{n-1}\) \(c_{\upsilon\mu}=\frac y2R_\mu,\ \ c_{p\mu}=\left(1+\frac y2\right)R_\mu\) (y = 3, 5, 6)
8Մայերի հավասարում \(c_p-c_\upsilon=R,\ \ k=\frac{c_p}{c_\upsilon},\ \ c_\upsilon=\frac{R}{k-1},\ \ c_p=\frac{kR}{k-1}\)

օդ՝ \(c_p\approx1005,\ c_\upsilon\approx718\) Ջ/(կգ·Կ)

9Էնթալպիա \(i=u+p\upsilon,\ \ \Delta i=c_p(T_2-T_1),\ \ q_p=i_2-i_1,\ \ i^*=i+\frac{c^2}{2}\)

Պրոցեսներ

10Իզոխոր \(\upsilon=\text{const}\) \(\frac{p_2}{p_1}=\frac{T_2}{T_1},\ \ \ell=0,\ \ q=\Delta u=c_\upsilon(T_2-T_1),\ \ \Delta s=c_\upsilon\ln\frac{T_2}{T_1}\)
11Իզոբար \(p=\text{const}\) \(\frac{\upsilon_2}{\upsilon_1}=\frac{T_2}{T_1},\ \ \ell=R(T_2-T_1),\ \ q=c_p(T_2-T_1)=i_2-i_1,\ \ \Delta s=c_p\ln\frac{T_2}{T_1}\)
12Իզոթերմ \(T=\text{const}\) \(\frac{p_2}{p_1}=\frac{\upsilon_1}{\upsilon_2},\ \ \Delta u=0,\ \ q=\ell=RT\ln\frac{\upsilon_2}{\upsilon_1}=RT\ln\frac{p_1}{p_2}\) \(\Delta s=R\ln\frac{\upsilon_2}{\upsilon_1},\ \ c=\pm\infty\)
13Ադիաբատ \(dq=0\) \(p\upsilon^k=\text{const},\ \ \frac{T_2}{T_1}=\left(\frac{\upsilon_1}{\upsilon_2}\right)^{k-1}=\left(\frac{p_2}{p_1}\right)^{\frac{k-1}{k}}\) \(\ell=-\Delta u=\frac{R}{k-1}(T_1-T_2)=\frac{p_1\upsilon_1-p_2\upsilon_2}{k-1},\ \ c=0\)

\(k\)՝ միատոմ 1,67, երկատոմ 1,40, եռատոմ 1,33

Հոսքի հավասարումներ (ԳՏՇ)

14Անխզելիություն \(G=c\rho F=\text{const},\ \ \frac{dc}{c}+\frac{d\rho}{\rho}+\frac{dF}{F}=0\)
15Էներգիա. մուտքային սարք, փողրակ \(q_{\text{արտ}}-\ell_{\text{արտ}}=i_2-i_1+\frac{c_2^2-c_1^2}{2}\) \(i_1+\frac{c_1^2}{2}=i_2+\frac{c_2^2}{2},\ \ i^*=\text{const},\ \ c_2=\sqrt{2(i_1^*-i_2)}\) \(c_{\text{սահմ}}=\sqrt{\frac{2k}{k-1}RT^*}\)
16Կոմպրեսոր \(\ell_{\text{կ}}=i_2^*-i_1^*=c_pT_1^*\left(\pi_{\text{կ}}^{*\frac{k-1}{k}}-1\right),\ \ \pi_{\text{կ}}^*=\frac{p_2^*}{p_1^*},\ \ N_{\text{կ}}=G\ell_{\text{կ}}\)
17Այրման խցիկ \(\ell_{\text{արտ}}=0,\ \ q_{\text{արտ}}=i_2^*-i_1^*=c_p(T_2^*-T_1^*),\ \ p\approx\text{const}\)
18Տուրբին \(\ell_{\text{տ}}=i_1^*-i_2^*=c_pT_1^*\left(1-\pi_{\text{տ}}^{*-\frac{k-1}{k}}\right),\ \ \pi_{\text{տ}}^*=\frac{p_1^*}{p_2^*},\ \ N_{\text{տ}}=G\ell_{\text{տ}}\)
19Արգելակված հոսք \(T^*=T+\frac{c^2}{2c_p},\ \ \frac{T^*}{T}=1+\frac{k-1}{2}M^2,\ \ \frac{p^*}{p}=\left(\frac{T^*}{T}\right)^{\frac{k}{k-1}}\)
20Բեռնուլի. մուտքային սարք, փողրակ \(-\ell_{\text{արտ}}=\int_1^2\upsilon\,dp+\frac{c_2^2-c_1^2}{2}+\ell_r,\ \ -\upsilon\,dp=c\,dc\ (\ell_r=0)\)

փողրակ՝ \(dp<0,\ dc>0\); դիֆուզոր՝ \(dp>0,\ dc<0\); \(\int\upsilon\,dp=\frac{n}{n-1}R(T_2-T_1)\)

21Բեռնուլի. կոմպրեսոր, տուրբին \(\ell_{\text{կ}}=\int_1^2\upsilon\,dp+\frac{c_2^2-c_1^2}{2}+\ell_r\) \(-\int_1^2\upsilon\,dp=\ell_{\text{տ}}+\frac{c_2^2-c_1^2}{2}+\ell_r\)

Ձայն, Մախ, գազադինամիկական ֆունկցիաներ

22Ձայնի արագություն \(a^2=\left(\frac{\partial p}{\partial\rho}\right)_s,\ \ a=\sqrt{k\frac p\rho}=\sqrt{kRT},\ \ a_{\text{օդ}}\approx20{,}05\sqrt T\) \(a_{\text{կր}}=\sqrt{\frac{2k}{k+1}RT^*}\)
23Մախի թիվ, λ \(M=\frac ca=\frac{c}{\sqrt{kRT}},\ \ \lambda=\frac{c}{a_{\text{կր}}},\ \ \lambda^2=\frac{\frac{k+1}{2}M^2}{1+\frac{k-1}{2}M^2},\ \ \lambda_{\text{սահմ}}=\sqrt{\frac{k+1}{k-1}}\)

\(M<1\) ենթաձայնային, \(M=1\) ձայնային, \(M>1\) գերձայնային

24Գազադինամիկական ֆունկցիաներ \(\tau(\lambda)=\frac{T}{T^*}=1-\frac{k-1}{k+1}\lambda^2,\ \ \pi(\lambda)=\tau^{\frac{k}{k-1}},\ \ \varepsilon(\lambda)=\tau^{\frac{1}{k-1}}\) \(q(\lambda)=\lambda\left(\frac{k+1}{2}\right)^{\frac{1}{k-1}}\varepsilon(\lambda),\ \ q_{\max}=q(1)=1\) \(G=m\frac{p^*}{\sqrt{T^*}}q(\lambda)F=m\frac{p}{\sqrt{T^*}}y(\lambda)F,\ \ y=\frac{q}{\pi},\ \ m_{\text{օդ}}=0{,}0404\)
