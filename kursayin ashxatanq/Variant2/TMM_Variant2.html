  1. 1. Երկարությունների մասշտաբը

    μl = իրական երկարությունգծագրային երկարություն = L1L1* = 0,340 մ200 մմ = 0,00170 մ/մմ

    Հակառակը՝ ցանկացած իրական երկարություն գծագրային դարձնելու համար այն բաժանում ենք μl-ի. օր.՝ ED* = 0,180 / 0,00170 = 105,9 մմ։

  2. 2. Լծակի ճոճման անկյունը

    ψ = 31,3°

    CDE լծակը ճոճվում է երկու եզրային դիրքերի միջև։ Այդ դիրքերը որոշվում են սողնակի ամենացածր (F₀′) և ամենաբարձր (F₀) դիրքերով։ ψ-ն այդ երկու դիրքերում DE-ի միջև եղած անկյունն է։

    1. Ստորին դիրք. DE-ն ուղղաձիգից շեղում ենք β = 3° → E₀′(84,5; 150,3)։ E₀′-ից EF* = 111,8 մմ շառավղով աղեղը հատում է ուղղորդը F₀′(90,0; 38,6) կետում։
    2. Վերին դիրք. F₀′-ից բարձրանում ենք HF* = 35,3 մմ → F₀(90,0; 73,9)։ F₀-ից 111,8 մմ աղեղը հատում է E-ի հետագիծը (D կենտրոնով, R = 105,9 մմ շրջանագիծը) E₀(30,4; 168,5) կետում։
    3. Անկյունը. DE₀-ն ուղղաձիգից շեղված է 34,3°, DE₀′-ը՝ 3°։

    Գծագրում՝ անկյունաչափով չափեք E₀DE₀′ անկյունը։

  3. 3. Կռունկ AB և շարժաթև BC

    AB* = 21,45 մմ, BC* = 152,95 մմ

    Լծակի եզրային դիրքերում կռունկը և շարժաթևը մեկ ուղղի վրա են։ Ձգված դիրքում դրանք գումարվում են (A—B—C), ծալված դիրքում՝ իրար վրա են ծալվում (B—A—C)։ Այսպիսով A-ից մինչև C₀ և C₀′ երկու հեռավորությունը տալիս են երկու հավասարում՝ երկու անհայտով։

    C₀-ն և C₀′-ը ստանում ենք DE₀-ն և DE₀′-ը 50°-ով պտտելով (լծակը կոշտ է), DC* = 95,3 մմ. C₀(115,9; 164,3), C₀′(159,7; 191,0), A(290,0; 173,6)։

    AC₀ = √(174,1² + 9,4²) = 174,4 մմ,   AC₀′ = √(130,3² + −17,4²) = 131,5 մմկամ չափեք քանոնով
    AB + BC = 174,4BC − AB = 131,5  ⇒  BC = 174,4 + 131,52 = 152,95 մմ,   AB = 174,4 − 152,95 = 21,45 մմ

    Իրական երկարությունները ստանալու համար գծագրայինը բազմապատկում ենք մասշտաբով.

    lAB = 21,45·0,00170 = 0,0365 մ,   lBC = 152,95·0,00170 = 0,2600 մ

  4. 4. Կռունկի անկյունային արագությունը

  5. 5. B կետի արագությունը և արագությունների մասշտաբը

    VB = 0,764 մ/վ, pb = 50,0 մմ

    B կետը պտտվում է A-ի շուրջը AB շառավղով, ուստի նրա արագությունը հավասար է անկյունային արագության և շառավղի արտադրյալին։ Այն ուղղահայաց է AB-ին և ուղղված է պտույտի կողմը (↻)։ Կռունկը պտտվում է հավասարաչափ, ուստի VB-ն բոլոր դիրքերում նույնն է։

    VB = ω1·lAB = 20,94·0,0365 = 0,764 մ/վ

    Արագությունների պլանում VB-ն պատկերում ենք pb հատվածով։ Տետրի օրինակի պես ընդունում ենք pb = 50 մմ, որից էլ ստացվում է մասշտաբը.

    μV = VBpb = 0,76450 = 0,01528 (մ/վ)/մմ

    Գծագրում՝ pb հատվածը տարեք p բևեռից ⊥ AB։

  6. 6. B կետի արագացումը և արագացումների մասշտաբը

    aB = 16,00 մ/վ², πb = 70,0 մմ

    ω1 = const, ուստի շոշափող արագացում չկա (ε1 = 0)։ Մնում է միայն նորմալ (կենտրոնաձիգ) արագացումը, որը միշտ ուղղված է B-ից դեպի պտտման կենտրոն A։

    aB = ω1²·lAB = 20,94²·0,0365 = 438,48·0,0365 = 16,00 մ/վ²

    Տետրի օրինակի պես ընդունում ենք πb = 70 մմ.

    μa = aBπb = 16,0070 = 0,2286 (մ/վ²)/մմπb ∥ AB, B → A

  7. 7. Աշխատանքային և պարապ ընթացքների անկյունները
