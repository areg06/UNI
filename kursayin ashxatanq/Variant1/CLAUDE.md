velocity & acceleration plans, A3 drawings). All user-facing text is in **Armenian**;
keep it Armenian when editing. The owner often requests changes from a phone via GitHub,
so make the change, rebuild, and commit the regenerated outputs in the same commit.

## Rebuilding (Python 3, standard library only)

```sh
cd source
python3 build.py      # -> ../TMM_Variant1.html (also writes source/variant1.html, gitignored)
python3 explain.py    # -> ../bacatrutyun.html
python3 tetr.py       # -> ../tetr.html
python3 export.py     # -> ../chertej_A3_{1,2}.svg (+ .png/.pdf only on the owner's Mac)
```

- Always edit the Python sources, never the generated HTML, then rerun the relevant script(s).
- If you change anything in `model.py`, `calc.py` or `sheet.py`, rerun **all** scripts that use it
  (build + explain + tetr, and export if the drawing changed).
- `export.py` needs Google Chrome at the macOS path for PNG/PDF. In a cloud/phone session only
  the SVGs get regenerated — say so, and tell the owner to run `python3 export.py` on the Mac
  to refresh the PNG/PDF.
- Numbers shown to the reader use a comma decimal separator (Armenian convention) via `calc.n()`.

## Optional explanation PDF export

Normal HTML generators still need only the Python standard library. The explanation PDF
export additionally needs Node.js, WeasyPrint 70.0 (and its Pango system library), FontTools,
and MathJax 3.2.2. For example, from the repository root:

```sh
python3 -m venv --system-site-packages /tmp/uni-print-venv
/tmp/uni-print-venv/bin/python -m pip install 'weasyprint==70.0' fonttools
npm install --prefix /tmp/uni-print-tools --no-audit --no-fund 'mathjax-full@3.2.2'
python3 'kursayin ashxatanq/Variant1/source/explain.py'
/tmp/uni-print-venv/bin/python 'kursayin ashxatanq/Variant1/source/print_explain.py' --mathjax-root /tmp/uni-print-tools/node_modules/mathjax-full
```

On macOS the exporter embeds the regular/bold Noto Sans Armenian faces from the system TTC;
on other systems install Noto Sans Armenian through fontconfig. Render and visually check
the PDF after editing. The interactive rotor is screen-only; static figures remain printable.
The explanation's sheet previews are reduced illustrations. Full-size drawings must be
printed from their separate A3/A4 PDFs at 100%, with fitting disabled.

Keep the acceleration scale (`MUACC`, μ_a) and the work scale (`MUWORK`, μ_A) in
`explain.py` distinct. They are 0.2909 (m/s²)/mm and 4.35 J/mm respectively; reusing
one substitution key silently corrupts the displayed acceleration equations.

## Optional narrated construction video

The video explains all four current sheets, including every velocity plan and the
position-2 acceleration plan. It stops at the current I_P / ΔT drawings; do not present
the reserved energy–mass area or the final flywheel selection as already calculated.
Drawings and numbers must continue to come from the canonical model and rounded notebook
chain, rather than a second copied numerical model.

Optional dependencies: Pillow, PyMuPDF, `piper-tts==1.8.0`, and FFmpeg (libx264 + libass).
The native Eastern Armenian voice is `hy_AM-gor-medium`, v3, by davit312:
https://huggingface.co/davit312/piper-TTS-Armenian (model metadata license: GPL-2.0).
Download both `v3/hy_AM-gor-medium.onnx` and its adjacent `.onnx.json` outside this repo.
The model author's inference example is at
https://huggingface.co/spaces/davit312/piper-TTS-Armenian/blob/main/app.py .
No voice cloning or account/API keys are used.

```sh
python3 -m venv --system-site-packages /tmp/uni-video-venv
/tmp/uni-video-venv/bin/python -m pip install 'piper-tts==1.8.0' Pillow PyMuPDF
/tmp/uni-video-venv/bin/python 'kursayin ashxatanq/Variant1/source/video_build.py' --voice-model /tmp/uni-piper-armenian/hy_AM-gor-medium.onnx
```

The builder keeps narration and encoded-scene caches under `/tmp/uni-video-cache`,
embeds chapter markers and captions, generates the player, and rejects an MP4 over
99 MB so it cannot exceed GitHub's single-file limit. `--preview /tmp/uni-video-preview`
renders scene stills; `--audio-only` builds only the narration. `--workers` controls parallel
encoding. Use `python3 source/video_page.py` from this folder to rebuild only the player.
Visually inspect every scene, spot-check narration, and validate the actual MP4 audio/video
and chapter streams before committing. Keep model weights, clips, WAVs and QA images out
of the repository; commit only the final video assets and sources.
